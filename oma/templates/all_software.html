All software

OMA provides several software tools for proteome quality assessment, orthology inference, functional inference, and downstream comparative genomics analyses.

This page gives a short overview of the main tools and points to the relevant GitHub repositories or documentation. For installation instructions, command-line options, examples, and troubleshooting, please refer to each tool's documentation.

Core OMA workflows

FastOMA

FastOMA infers orthologs and HOGs from custom protein datasets. Use FastOMA if you want to analyse your own genomes or proteomes rather than only browsing precomputed results in the OMA Browser.

Links: GitHub & Documentation | Publication

OMAmer

OMAmer maps protein sequences to OMA HOGs. It is useful when you have new protein sequences and want to place them into the existing OMA framework without running a full orthology inference pipeline.

Links: GitHub & Documentation | OMAmer database files | Publication

OMArk

OMArk assesses the quality and completeness of proteome annotations using OMA HOGs. It can help identify missing genes, contamination, fragmented annotations, or other issues in predicted proteomes.

Links: GitHub & Documentation | Web tool | Publication

Comparative genomics and downstream analysis

pyHam

pyHam is a Python library for analysing HOGs and their evolutionary histories. It is useful for programmatic analysis of gene gain, duplication, loss, and retention across a species tree.

Links: GitHub | Documentation | Tutorial | Publication

EdgeHOG

EdgeHOG uses HOGs to infer ancestral gene order. It is useful for comparative genomics analyses involving gene neighbourhoods, ancestral contigs, and genome organization.

Links: GitHub & Documentation | Publication

HogProf

HogProf performs phylogenetic profiling based on HOG presence and absence patterns. It can be used to identify genes with similar evolutionary profiles across species.

Links: GitHub & Documentation | Publication

orthoXML-tools

orthoXML-tools provides utilities for working with orthology data in orthoXML format.

Links: GitHub & Documentation | Publication

Comparative genomics and downstream analysis

FoldTree

FoldTree builds phylogenetic trees using information from protein structures. Use it when structural information is central to the phylogenetic analysis.

Links: GitHub & Documentation | Publication

Read2Tree

Read2Tree reconstructs phylogenetic trees directly from sequencing reads by mapping reads to marker genes. It is useful when assembled genomes or predicted proteomes are not available.

Links: GitHub & Documentation | Publication

AmpliPhy

AmpliPhy is a scalable, fully automated Nextflow pipeline for improving gene tree inference through database-driven homolog enrichment.

Links: GitHub & Documentation | Publication

Other tools

ALF

ALF simulates a root genome into a number of related genomes.

Links: GitHub & Documentation | Web tool | Publication

OMAnnotator

OMAnnotator is a workflow for combining protein-coding gene structural annotation from different sources, using evolutionary information from other species.

Links: GitHub & Documentation | Publication

OMA-MO

Provides the user with the best non-complex organism for research into a biological process of interest based on orthologous relationships between human and the species.

Links: GitHub & Documentation | Web tool | Publication

QTLSearch

QTLSearch prioritizes candidate causal genes in QTL regions by combining trait-associated functional annotations with OMA HOGs. It is useful for QTL studies where candidate regions contain many genes and functional information from related species can help rank likely causal candidates.

Links: GitHub & Documentation | Publication

Legacy software

OMA Standalone

OMA Standalone is the legacy standalone implementation of OMA orthology inference. For most new analyses, FastOMA is recommended.

Links: GitHub | Documentation | Publication

ESPRIT2

ESPRIT is a legacy tool associated with earlier OMA workflows.

Links: GitHub & Documentation | Publication
