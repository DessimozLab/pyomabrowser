This tool extracts a set of universal, single-copy marker genes (OMA Groups) from your selected genomes, suitable for reconstructing a species phylogeny (e.g. as input to a tool such as RAxML or IQ-TREE). The dataset contains individual FASTA files with unaligned protein sequences (.fa) and coding sequences (.fna).

Important limitations and notices

  • Only genes present in at least the specified minimum fraction of selected species are considered as markers. Lowering this fraction yields more markers but with more missing data per species.

  • If more groups qualify as markers than the specified limit, only the most complete groups (i.e. those with the fewest missing species) are returned.

Species trees can be inferred, for example, using the super-matrix approach described in the F1000 Research Protocol.
