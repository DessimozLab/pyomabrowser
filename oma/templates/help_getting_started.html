Get started with OMA

OMA is a database and method for inferring evolutionary relationships among genes from complete genomes. It provides precomputed orthology relationships, gene families, genome-level views, downloadable datasets, and tools for comparative genomics. Use this page if you are new to OMA and want to understand what kind of result you need.

What can I do with OMA?

With OMA, you can:

  • Find orthologs of a gene across species
  • Explore gene families using HOGs
  • Identify strict sets of orthologs for phylogenetic analysis
  • Browse extant and ancestral genomes
  • Compare gene order and synteny between species
  • Download OMA data for large-scale analyses
  • Access OMA programmatically through APIs and wrappers
  • Run OMA-related tools on your own data
For most users, the first step is to search for a gene, species, HOG, or group from the OMA Browser home page.

What is orthology?

Orthologs are genes in different species that started diverging through a speciation event. They are often used to transfer functional information between species, infer species trees, and study gene family evolution.

Orthology is different from paralogy. Paralogs are genes that started diverging through a duplication event.

A gene can have different types of orthology relationships depending on the evolutionary history of the gene family. For example:

  • one-to-one orthology: each species has a single corresponding gene
  • one-to-many orthology: one gene corresponds to multiple genes in another species, usually because of a duplication
  • many-to-many orthology: both lineages contain duplicated copies

Which OMA result should I use?

OMA provides several types of orthology results. They are related, but useful for different tasks.

Pairwise orthologs

Use pairwise orthologs when you want to find the orthologs of one gene in one or more species.

This is usually the best starting point if your question is:

  • "What is the ortholog of my gene in another species?"
  • "Does this gene have one-to-one or one-to-many orthologs?"
  • "Which species have an ortholog of this gene?"

Pairwise orthologs are shown on gene pages and can be filtered by species, taxonomic range, relation type, or supporting evidence.

Hierarchical Orthologous Groups

Use HOGs when you want to study a gene family across evolution.

HOGs contain genes that descend from a common ancestral gene at a given taxonomic level. Because HOGs are hierarchical, a broad HOG can contain smaller subHOGs defined at more recent taxonomic levels.

HOGs are useful if your question is:

  • "Which genes belong to this gene family?"
  • "How did this gene family evolve?"
  • "Where did duplications or losses occur?"
  • "Which genes were present in an ancestral genome?"
  • "How does this family look at different taxonomic levels?"

Strict Orthologous Groups

Use Strict Orthologous Groups (formerly called OMA Groups) when you need a stringent set of genes that are all orthologous to one another.

These groups are especially useful for phylogenetic marker selection and species tree inference. Because the groups are strict, they contain at most one gene per species.

Use them if your question is:

  • "Which genes can I use as markers for a species tree?"
  • "Which genes are all mutually orthologous?"

Type of ortholog Best for Typical question
Pairwise orthologs Gene-by-gene orthology What is the ortholog of this gene in another species?
HOGs Gene family evolution How did this gene family evolve across a clade?

How do I search OMA?

From the OMA Browser home page, you can search by:

  • gene identifier
  • protein sequence
  • HOG identifier
  • Strict Orthologous Group identifier
  • species name
  • common name
  • NCBI taxon ID
  • full text

OMA search uses search tokens. When you type a query and press Space or Enter, OMA turns the query into a token with a category prefix.

Each token represents either a Gene, HOG, OMA group, or Taxon. Prefixes are used to specify which category to associate with the query term. Choose the prefix that matches what you are searching for:

Category Prefixes
Genes id, go, ec, description, domain, sequence
HOGs hog, sequence
SOGs omagroup, fingerprint, sequence
Taxon species, taxid, taxon

For multi-word searches, use quotation marks. For example:

species:"Homo sapiens"

Taxon tokens can also be combined with other token types. For example:

hog:60627 species:HUMAN

This searches for human genes found in HOG 60627.

Searching for a gene takes you to a gene page. Searching for a HOG or group takes you to a group page. Searching for a species or ancestral taxon takes you to a genome page.

Common first tasks

I have a gene and want its orthologs

Search for the gene identifier or protein sequence, then open the gene page. The ortholog table is shown by default.

Go to: Find orthologs for a gene

I want to understand a gene family

Search for a HOG identifier, or open the HOG from a gene page. Use the HOG page to view members, taxonomic levels, and evolutionary events.

I want to browse a species or ancestral genome

Search for a species name, common name, or NCBI taxon ID. You can browse genome information, genes, HOGs, related species, and synteny views.

Use the Downloads menu for release-wide files, or download filtered tables directly from browser pages.

Use OMA-related software depending on your task. Use FastOMA for orthology inference on custom genomes, OMAmer to map proteins to existing OMA HOGs, and OMArk to assess proteome quality.

Key terms

Gene / entry

A protein-coding sequence represented in OMA. OMA uses one representative protein sequence per locus for orthology inference.

OMA identifier

The identifier for a gene in OMA. It consists of a five-letter species code followed by a unique number. Example: WHEAT00001.

HOG

A hierarchical orthologous group. A HOG contains genes descended from a common ancestral gene at a specific taxonomic level.

RootHOG

The deepest HOG containing all genes in a gene family across the species represented in OMA.

Strict Orthologous Group

A stringent group of genes that are all orthologous to one another. Formerly referred to as OMA Groups.

Ancestral genome

In OMA, an ancestral genome is represented by the HOGs inferred to be present at a given ancestral taxonomic level.

Synteny

Conservation of gene order between genomic regions. OMA provides tools to explore both local and broader synteny patterns.

More key terms can be found in the Glossary.
