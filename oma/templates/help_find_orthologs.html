Find orthologs for a gene

Use this page if you have a gene or protein sequence and want to find its orthologs in other species.

OMA provides several ways to search for a gene, inspect its orthology relationships, filter the results, and download the data.

Before you start

You can search for a gene using:

  • an OMA identifier
  • a UniProt ID or another cross-reference
  • a protein sequence
  • a gene or protein name
  • full-text search

OMA identifiers consist of a five-letter species code followed by a unique number, for example HUMAN04376.

Search for a gene

From the OMA Browser home page, use the main search bar to search for your gene of interest.

You can choose the search type from the dropdown menu next to the search bar. Searches can be done using identifiers, protein sequences, full text, OMA fingerprints, or NCBI taxon IDs.

If your search matches a gene in OMA, you will be taken to a gene page. Gene pages contain information about one OMA entry, including its orthologs, paralogs, gene information, isoforms, GO annotations, sequences, and local synteny.

Understand the gene page

At the top of a gene page, you will see the main identifiers for the gene, including its OMA ID and available cross-references such as UniProt or source database IDs.

The side menu gives access to different types of information for the gene:

  • Orthologs: genes in other species inferred to be orthologous to the query gene
  • Paralogs: genes related to the query gene by duplication
  • Gene information: description, organism, coordinates, exon number, and cross-references
  • Isoforms: alternative splice variants, when available in OMA
  • GO annotations: Gene Ontology annotations with evidence codes and references
  • Sequences: protein and coding DNA sequences
  • Local synteny: neighbouring genes and conserved gene order around the query gene

The ortholog table is usually the main starting point.

Interpret the ortholog table

The ortholog table lists genes inferred to be orthologous to your query gene.

The table can include several types of orthology evidence:

  • Pairwise orthologs
  • HOG-induced orthologs
  • Strict Orthologous Group-induced orthologs

These evidence types are related but not identical. Pairwise orthologs are inferred directly between genes. Pairwise orthologs are used to build the HOGs. HOG-induced orthologs come from membership in the same HOG at the relevant taxonomic level. Strict Orthologous Group-induced orthologs come from membership in a stricter group of mutually orthologous genes.

The table also shows information such as:

  • domain of life
  • species or taxon
  • protein ID / OMA identifier
  • orthology relation type
  • cross-references
  • protein domain architecture

Understand relation types

The relation type describes whether the orthology relationship is one-to-one or involves duplicated genes.

Relation type Meaning
1:1 Each species has one corresponding ortholog between species
1:many The query gene has multiple orthologs in the other species
many:1 Multiple genes in the query species correspond to one gene in the other species
many:many Both lineages have duplicated copies

A one-to-many or many-to-many relationship usually means that gene duplication occurred after the relevant speciation event.

Choose the orthology evidence to display

Use Required orthology evidence in the side menu to choose which types of orthologs to show.

You can display:

  • only pairwise orthologs
  • only HOG-induced orthologs
  • only Strict Orthologous Group-induced orthologs
  • combinations of the above

For many common gene searches, pairwise orthologs are the most direct result. If you are working with gene families or taxonomic levels, HOG-induced orthologs may be more relevant. If you need a stringent set of mutually orthologous genes, use Strict Orthologous Group-induced orthologs.

Filter by species or taxon

Use taxonomic filters to restrict the table to a species or clade of interest.

You can:

  • filter by a predefined taxonomic range
  • add a custom taxonomic filter
  • search within the table for a species, gene ID, or relation type
  • show or hide columns using the table settings

Filtering is useful when the full ortholog table is large or when you only care about a specific group of species, such as mammals, insects, plants, or bacteria.

Download the results

You can download the ortholog table using the download icon at the upper right of the table.

Downloads preserve the filters currently applied to the table. This means you can first restrict the results to a species, clade, relation type, or evidence type, and then export only that subset.

Available formats may include:

  • CSV
  • TXT
  • JSON
  • XML
  • SQL
  • Excel

For larger datasets, use the Downloads menu or programmatic access through the REST API, SPARQL endpoint, or Python/R packages.

Find paralogs of a gene

The gene page also includes a Paralogs section.

Paralogs are homologous genes that started diverging through a duplication event. In the OMA browser, paralogs are derived from HOGs and are defined with respect to the taxonomic level where the duplication occurred.

The paralogs table follows a similar format to the ortholog table.

View gene information

The Gene information section provides general information about the query gene, including:

  • gene description
  • organism
  • genomic coordinates
  • number of exons
  • source identifiers
  • cross-references

This section is useful for confirming that you are looking at the correct gene.

View GO annotations

The GO annotations section lists Gene Ontology annotations for the gene, including evidence codes and reference information.

GO annotations are organized into:

  • Biological Process
  • Molecular Function
  • Cellular Component

These annotations can help interpret the likely function of the gene and its orthologs.

Check isoforms

The Sequences/Isoforms section lists alternative splice variants for the gene, when this information is available in OMA.

If no isoforms are shown, this does not necessarily mean that the gene has no isoforms. It may mean that isoform information is not available in OMA for that genome.

Download sequences

The Sequences/Isoforms section provides the protein and coding DNA sequences for the gene, when available.

Sequences can be downloaded in FASTA format.

Explore local synteny

The Local Synteny Viewer shows the genomic neighbourhood around the query gene and its orthologs.

This can help you inspect whether neighbouring genes are conserved across species. Conserved local synteny can support orthology relationships, reveal rearrangements, and help detect possible annotation or assembly issues.

In the viewer, genes are shown as boxes. Orthologous genes are connected or coloured consistently across neighbouring regions. Clicking on a gene can recenter the display around that gene.

Common pitfalls

I cannot find my gene

Try searching with a different identifier, a protein sequence, or a full-text query (must be put in quotes if more than one word). Some identifiers may differ between source databases.

My species is missing

OMA only contains species included in the current OMA release. Check the species/release information page or use OMAmer/FastOMA if you want to work with your own data.

There are several orthologs in one species

This usually reflects gene duplication. Check the relation type: one-to-many and many-to-many orthology relationships are expected for many gene families.

The ortholog table is very large

Use taxonomic filters, relation type filters, or evidence filters to narrow the table before interpreting or downloading it.

Different evidence types give different results

Pairwise orthologs, HOG-induced orthologs, and Strict Orthologous Group-induced orthologs are inferred or derived differently. Use the evidence type that best matches your question.
