Use the following form to download the list of all predicted orthologs between a pair of genomes of interest. The result is returned either as a tab- or comma separated text file, where each line corresponding to one orthologous relation. The columns will contain the OMA IDs and all the selected cross-references for both genomes, the type of orthology (1:1, 1:n, m:1 or m:n) and (if available) the OMA group containing both sequences. The json format will contain additional information for the genes of each orthologous relation.
