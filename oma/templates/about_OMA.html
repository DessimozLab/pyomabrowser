About OMA

OMA is a resource for inferring, accessing, and analysing orthologs across complete genomes. It provides precomputed orthology relationships, HOGs, gene family information, genome-level views, downloadable data, and tools for comparative genomics.

The OMA Browser is developed and maintained as part of the OMA ecosystem, with support from the Swiss Institute of Bioinformatics and collaborating academic institutions.

The OMA Standalone algorithm

The OMA browser’s inference algorithm consists of three main phases. First, to infer homologous sequences (sequences of common ancestry), all-against-all Smith-Waterman alignments are computed and significant matches are retained. Second, to infer orthologous pairs (the subset of homologs related by speciation events), mutually closest homologs are identified based on evolutionary distances, taking into account distance inference uncertainty and the possibility for differential gene losses (for more details, see Roth et al 2008). Release notes

OMA is updated regularly. Each release may include new genomes, updated genome annotations, improvements to orthology inference, and changes to available files or tools.

Use the release notes to:

  • check what changed in the latest release
  • identify which genomes or annotations were updated
  • find the OMA release used in a previous analysis
  • support reproducibility in published work

When publishing analyses based on OMA, include the OMA release version and the date you accessed or downloaded the data.

About us

The OMA project was initiated in 2004 at ETH Zurich by Prof. Gaston Gonnet, with the goal of identifying orthologs among all publicly available genomes. The OMA Browser was introduced in 2006. In 2012, OMA became a SIB-funded bioinformatics resource. To date, OMA underwent 24 major releases, steadily increasing the number of genomes under consideration.

OMA is now developed by the Comparative Genomics Lab and collaborators. The project brings together expertise in orthology inference, comparative genomics, bioinformatics software development, phylogenomics, and data infrastructure.

The OMA ecosystem includes:

  • the OMA Browser
  • downloadable OMA release data
  • programmatic access through REST, SPARQL, Python, and R
  • web tools for orthology, HOGs, synteny, phylogenetic profiling, and functional analysis
  • software for running OMA-related analyses on custom data

OMA is part of the SwissOrthology initiative and is supported by the Swiss Institute of Bioinformatics.
