Explore extant and ancestral genomes

Use this page if you want to browse an extant species, inspect an ancestral genome, explore gene content, or visualize gene order and synteny. Note that by "genome" we are referring to the protein-coding gene repertoire.

OMA provides genome-level pages for both extant genomes and ancestral genomes. Extant genomes represent species included in the current OMA release. In OMA, an ancestral genome represents the inferred protein-coding gene repertoire of a common ancestor. Each HOG at that taxonomic level acts as a proxy for one ancestral gene, and the full set of HOGs at that level approximates the ancestral gene content. Users can therefore browse ancestral "genes", trace gains and losses, and explore gene repertoire evolution across the species tree.

What can I do from a genome page?

Genome pages let you:

  • view information about a species or ancestral taxon
  • browse the genes in an extant genome
  • browse HOGs inferred in an ancestral genome
  • inspect related species
  • explore gene order
  • compare synteny between genomes
  • download genome-level tables

Use genome pages when your starting point is a species, clade, or genome, rather than a single gene.

Find an extant genome

An extant genome is the protein-coding gene repertoire of a species currently represented in OMA.

To find an extant genome, search for the species using one of the taxon search prefixes:

  • species for a scientific or common species name
  • taxid for an NCBI taxonomy ID
  • taxon for a broader taxonomic term

Examples:

  • species:"Homo sapiens"
  • species:human
  • taxid:9606
  • taxon:Mammalia

After typing the query, press Space or Enter to create the search token. For multi-word species names, use quotation marks.

You can also access genome pages from gene pages by clicking the Genome link.

Find an ancestral genome

An ancestral genome represents the inferred protein-coding gene content of a common ancestor at a particular taxonomic level, not a directly sequenced genome.

In OMA, ancestral genomes are built from HOGs. At a given ancestral taxonomic level, each HOG acts as a proxy for one ancestral gene. The full set of HOGs inferred at that level approximates the gene content of the common ancestor.

To find an ancestral genome, search for the clade or taxonomic group whose common ancestor you want to inspect using a taxon token.

Examples:

  • taxon:Mammalia
  • taxon:Chordata
  • taxon:Hominidae
  • taxon:Viridiplantae
  • taxid:40674

After typing the query, press Space or Enter to create the search token. For multi-word clade names, use quotation marks.

On an ancestral genome page, the "ancestral genes" table lists HOGs inferred to have been present in that ancestor. These can be used to explore ancestral gene content, gene gains, losses, duplications, and changes in gene repertoires across evolution.

Understand the genome page

A genome page summarizes information about an extant or ancestral genome.

For an extant genome, the page shows:

  • scientific name
  • common name
  • OMA species code
  • NCBI taxon ID
  • proteome annotation source
  • release or update information
  • number of proteins or genes
  • number of genes assigned to HOGs or Strict Orthologous Groups

For an ancestral genome, the page shows:

  • ancestral taxon or clade name
  • species included in the clade
  • inferred ancestral gene content
  • HOGs present at that ancestral level
  • OMA taxon identifiers or related metadata

The side menu gives access to genome information, the chromosome viewer, and gene or HOG lists.

Browse HOGs in an ancestral genome

For an ancestral genome, the gene list is represented as HOGs present at that taxonomic level.

Each HOG can be treated as an inferred ancestral gene. You can click on a HOG to open the corresponding HOG page and inspect its members, subHOGs, and evolutionary history.

The ancestral gene table can also be downloaded from the page.

Explore ancestral gene order

The Ancestral Contig Viewer shows the gene order inferred for an ancestral genome. Ancestral genes are represented by HOGs, while the connections between neighbouring HOGs represent ancestral gene adjacencies inferred with EdgeHOG from gene order observed in descendant species.

Ancestral genes are grouped into ancestral contigs (contiguous regions of reconstructed gene order) and the contigs are shown from largest to smallest.

Each contig has two linked views:

  • an overview showing the full contig and the location of the region currently being viewed;
  • a detailed excerpt where individual ancestral genes and their inferred adjacencies can be inspected.

By default, gene colour indicates the HOG completeness score, gene height reflects the number of extant genes descending from that ancestral gene, and edge colour shows the inferred age of the adjacency. These properties can be changed using the viewer settings.

You can:

  • pan and zoom along an ancestral contig;
  • search for and highlight a HOG;
  • click genes or adjacencies to inspect their details;
  • select a region containing several ancestral genes and run GO enrichment on the selected set;
  • export individual contigs or the complete visualization.

See the Chromosome Viewer documentation for a detailed explanation of the display, metrics, navigation, and EdgeHOG reconstruction.

Browse genes in an extant genome

The gene list contains the proteins represented in an extant genome.

The table includes:

  • OMA protein ID
  • cross-references
  • HOG ID (if any)
  • evolutionary event which led to gene from parent ancestor
  • domain architecture
  • species or taxon information
  • locus or positional information, when available

OMA protein IDs are usually ordered according to locus position in the genome. This can make it easier to inspect local patterns such as tandem duplications, especially when neighbouring genes have similar domain architectures.

Explore related species

The Related species section helps identify species that are most or least related to the selected genome based on shared OMA Groups or HOGs.

This can be useful when choosing species for comparative analysis, identifying close relatives in the OMA database, or checking how well a clade is represented.

Explore extant gene order

The Chromosome Viewer can also be used to explore gene order in an extant genome.

Each chromosome, scaffold, or contig is shown using two linked views:

  • an overview of the full genomic region;
  • a detailed excerpt showing individual genes and their local gene order.

The overview indicates where the currently displayed excerpt lies within the chromosome or scaffold. Pan and zoom in the excerpt to inspect neighbouring genes and larger or smaller genomic regions.

Gene colour and height can be used to display different gene properties, and connections between neighbouring genes can display information inferred from comparative gene order, such as the evolutionary conservation of an adjacency.

You can:

  • pan and zoom along chromosomes or scaffolds;
  • inspect individual genes;
  • search for and highlight genes of interest;
  • select a group of genes and run GO enrichment;
  • customize which properties are represented by gene colour, gene height, and adjacency colour;
  • export the visualization.

See the Chromosome Viewer documentation for a detailed explanation of the display and available metrics.

Explore synteny between two genomes

Synteny refers to conserved gene order between genomic regions.

In OMA, synteny can be explored at different scales:

  • local synteny: conservation around a query gene and its neighbouring genes
  • genome-level synteny: broader comparison between chromosomes, scaffolds, or contigs, represented as a synteny dotplot

To explore genome-level synteny, select a second species from the synteny section of the genome page. OMA then shows a synteny matrix comparing the two genomes.

In the matrix, each square represents a chromosome or scaffold pair. The colour intensity reflects the number of shared one-to-one orthologs, or the number of points in the corresponding synteny dot plot.

Click a square to open the synteny dot plot for a specific chromosome or scaffold pair.

Common pitfalls

An ancestral genome is not a sequenced genome

An ancestral genome in OMA is an inference. It represents HOGs predicted to be present in a common ancestor, not a directly observed genome sequence. We do not provide consensus sequences for the HOGs.

An ancestral gene corresponds to a HOG

At an ancestral taxonomic level, each ancestral gene is represented by a HOG inferred to be present at that level.

Synteny requires suitable genome assemblies

Synteny views depend on gene order information. Assemblies with many short scaffolds or incomplete annotation may give sparse or fragmented synteny views.

A weak synteny signal does not always mean no relationship

Gene order can be disrupted by rearrangements, duplications, annotation differences, or fragmented assemblies. Interpret synteny together with orthology evidence.

Extant and ancestral pages answer different questions

Use extant genome pages to inspect a species currently in OMA. Use ancestral genome pages to inspect inferred gene content at a clade or ancestral taxonomic level.
