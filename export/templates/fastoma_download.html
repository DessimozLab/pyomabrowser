Here we provide a convenient interface to download proteomes from OMA ready to be used with FastOMA and other tools within the OMA ecosystem.

Export of Genomes for FastOMA

The data we provide in here is intended to be used as input data for FastOMA. The compressed tar-file must be deflated prior of using it in FastOMA. You would normally want to add additional proteomes to this dataset by adding the respective files in the proteome and splice folders.
